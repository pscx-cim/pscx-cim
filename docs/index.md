# pscx-cim developer documentation

pscx-cim converts PSCAD `.pscx` cases into IEC 61970/61968 CIM documents
and reads them back. The [guide](../guide/index.md) is for people running
`pscx`. These pages are for people changing it.

Read [Architecture](architecture.md) first: it follows a library and a case
through the code, module by module. [EMTIOP](emtiop.md) explains how the
documents relate to the EMTIOP profile.
