# pscx-cim

`pscx-cim` converts PSCAD 5.0 `.pscx` cases to IEC 61970/61968 CIM
document sets and reads those sets back into a `.pscx`.

not affiliated with or endorsed by Manitoba Hydro International.

## CIM+

CIM+ is IEC 61970/61968 CIM. Its classes come from three sources:

| Source | Examples |
|---|---|
| The CGMES 3.0 profiles | `ACLineSegment`, `ConnectivityNode`, `Terminal` |
| Core CIM (Grid18 v15), for classes that CGMES 3.0 does not profile | `DetailedModelTypeDynamics`, `ParameterDescriptor`, `ParameterValue` |
| The EMT vocabulary in [src/pscx/profiles/emt/](src/pscx/profiles/emt/EMT.md) | `emt:LibraryModelType`, `emt:ParameterCategory` |

A concept uses a CGMES 3.0 class where one exists, then a core CIM class,
and an `emt:` class only where neither standard has one. Core CIM supplies
the detailed-model classes, which describe a model by a type and a list of
named parameters; EMTIOP uses the same classes. Both standard sources share
the `cim:` namespace (`http://iec.ch/TC57/CIM100#`).
[docs/emtiop.md](docs/emtiop.md) compares this representation with EMTIOP.

The vocabulary consists of three files in `src/pscx/profiles/emt/`:

- `EMT-AP-Voc-RDFS.rdf` is the vocabulary itself, an RDFS profile in the
  CGMES conventions.
- `EMT-AP-Con-SHACL.ttl` holds the vocabulary's own constraints. It is
  derived from the vocabulary by `tools/gen_emt_shacl.py` and does not depend
  on any library.
- `EMT.md` is a readable reference to the vocabulary with a class diagram,
  generated by `tools/dump_profile.py --markdown`.

## Install

```bash
uv sync
```

You provide the PSCAD master library yourself, and the repository does
not include it. `master.pslx` is downloadable from the PSCAD website.
Point `PSCAD_MASTER` at it:

```bash
export PSCAD_MASTER=/path/to/master.pslx
```

[Getting started](guide/start.md) covers installing with pip, setting the
variables in PowerShell, and a first conversion.

## Use

```bash
uv run pscx emit CASE.pscx --out DIR   # write the nine CIMXML documents for one case
uv run pscx check DIR                  # report where a document set disagrees with its own re-emission
uv run pscx read DIR --out CASE.pscx   # rebuild the .pscx from the nine documents
uv run pscx CASE.pscx                  # print the extracted netlist (--flatten for the whole-project view)
```

`pscx read` refuses a set whose documents disagree with each other unless
you choose a side. `--prefer-source` keeps the statements of record, and
`--prefer-interchange` applies the engine values wherever they can be
traced back to a stated parameter.

`pscx CASE.pscx --workspace FILE.pswx` (also accepted by `pscx emit`)
loads the projects a workspace names alongside the case. The
[guide's CLI chapter](guide/cli.md) covers every option and exit
code.

## Entry points for maintainers

This is a map only. Each module's docstring states its full contract.

- `pscx.io.read_project(path)` parses a `.pscx` or `.pslx` into an
  `HirProject`. Every path through the code uses this one reader.
- `pscx.elaborate.flatten(case_path)` produces the `FlatProject` that the
  rest of the pipeline reads.
- `pscx.cim.emit_files(flat, out_dir, project=...)` writes the documents
  for one case.
- `pscx.reader.read_documents(paths)` decodes the documents back into an
  `HirProject`. `pscx.reader.read_case` wraps it with the divergence check
  and takes a `Precedence` when a side must be chosen.
- `pscx.check.check_documents(paths)` reports where a set disagrees with
  its own re-emission, with each disagreement classified and attributed.
  It repairs nothing.
- `pscx.write.write_project(project)` builds the `.pscx` XML tree from an
  `HirProject`. Both `pscx read` and the round-trip tests end here.

Each inverse sits in the same module as the mapping it inverts.
`pscx.emission` holds the projection and its inverse, `reconstruct()`.
`pscx.dl`, `pscx.surface` and `pscx.record` each hold the inverse of their
own document, and `pscx.rules` holds the declarative tables that
`reconstruct()` reads. `tests/test_reconstruction_inventory.py` lists,
field by field, what the exchange must carry.
